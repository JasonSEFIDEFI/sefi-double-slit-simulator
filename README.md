# SEFI Double-Slit Waveform & Observed Electron Simulator

This project is a SEFI/DEFI geometric interpretation of the classic double-slit experiment.  
The interference field is rendered as a continuous SEFI geometry; the observed electron is a localized DEFI entity that samples and distorts the field at its position.

As the electron moves across the screen, it interacts with the interference pattern, building geometric tension. When tension crosses a collapse threshold, the field snaps into a new configuration, giving a geometric, non-symbolic view of observation in the double-slit context.

## Run

npm install  
npm run dev
